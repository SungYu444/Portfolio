## Hosting

GitHub Pages publishes this static HTML, CSS, and JavaScript site using
[the Pages workflow](.github/workflows/pages.yml). Every push to `main` deploys
the site; it can also be run manually from the repository's Actions tab.
In Settings > Pages, keep the build source set to **GitHub Actions**.

No dependency installation or build command is needed for deployment:
`assets/ascii-sharks.js` is already bundled and committed. If you change its
TypeScript sources, rebuild it using the command in
[the upstream notes](vendor/ascii-sharks/UPSTREAM.md) and commit the updated bundle.
Keep local asset URLs relative so they work under the `/Profolio/` project path.
